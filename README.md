# monarch-lazyvpn

A native WireGuard VPN manager for Linux, with a GPUI interface and headless CLI.

- ProtonVPN and custom WireGuard profiles
- Search, favorites, keyboard navigation and profile editing
- nftables killswitch and split-tunnel detection
- System keyring with encrypted credential fallback
- Live Noctalia colors and status output for bars and scripts

## Install

On Monarch:

```bash
monarch install lazyvpn
```

Launch with **Mod+Ctrl+V** or `monarch-lazyvpn`. Monarch sets up the Niri window
rule and Noctalia integration. `monarch remove lazyvpn` keeps your profiles and
credentials.

### From source

Requires a current Rust toolchain, WireGuard tools, nftables and the GPUI Linux
dependencies: Wayland, libxkbcommon, libxkbcommon-x11, libxcb, Fontconfig,
FreeType, OpenSSL and a working graphics driver. File selection uses the desktop
portal.

```bash
cargo build --release
sudo ./install/setup-permissions.sh install
bash install/setup-gui.sh
```

The GUI installer uses `~/.local/bin`, which must be on your PATH. The permissions
setup enables VPN operations for users in the `wheel` or `sudo` group. On
Noctalia, the GUI installer also sets up live colors.

For CLI-only builds, use `cargo build --release --no-default-features`.

## Use

Open the app and import a WireGuard `.conf` file with **Import** or `i`.
ProtonVPN imports load its server catalog; other configurations stay as personal
profiles. Select a server and connect. Custom profiles have **Edit**, **Rename**
and **Delete** actions; disconnect before modifying them.

Saved profiles appear immediately while server updates run in the background.
They remain available when an update fails. Launching again focuses the existing
window on Niri; on other compositors, select it manually.

Protection settings apply when connecting. Split tunnels do not enable the
killswitch. Closing the app keeps the VPN connected by default; change
**Keep VPN on exit** to disconnect on close.

### Keyboard

- `j` / `k` or arrows: navigate; Left/Right: fold or expand provider groups
- `Enter`: connect/disconnect or toggle a group; `d`: disconnect
- `/`: search; `f`: favorite; `i`: import; `r`: refresh
- `?`: help; `Esc`: dismiss a dialog or return to the list; `q`: quit

### CLI and status

```bash
monarch-lazyvpn --help
monarch-lazyvpn --format json status
monarch-lazyvpn list-servers --country FR
monarch-lazyvpn import profile.conf
monarch-lazyvpn connect SERVER_ID
monarch-lazyvpn disconnect

monarch-lazyvpn-status --format=waybar
monarch-lazyvpn-status --format=text
```

CLI commands work without a graphical session. Close the GUI before running
commands other than status. Only one VPN manager can run at a time; its lock is
released automatically after a crash.

## Configuration

Files live in `~/.config/monarch-lazyvpn/` (or `$XDG_CONFIG_HOME/monarch-lazyvpn/`):

- `config.toml`: settings, favorites and configured providers
- `servers/`: custom WireGuard profiles
- `theme.json`: palette generated by Noctalia

Common settings:

```toml
killswitch_enabled = true
killswitch_allow_lan = true
keep_vpn_on_exit = true
```

## Development

```bash
cargo test

```

Preview uses sample profiles without loading credentials or changing VPN settings.
Use release builds when measuring startup performance.
